# Dress-Up Game
This project is a fun and interactive dress up game that lets you customize three avatars. You can change their gender, skin tone, clothes, and name them while unlocking achievements as you play.


# User Manual:
This was created in Apache Netbeans IDE. First, make sure to download all the resources and place the "resources" folder in the "main" folder of the project through File Explorer so that the program can run without error. After pressing the start button in the title scene, the user is asked to create a username to enter the game. In the closet scene, there are three buttons that lead to the avatar editor scene, buttons that let you edit the avatar's names, a button that takes you to the user info scene, and a finish button. In the avatar editing scene, the user first picks a skin tone and gender, and then freely scroll through the clothes to dress up their avatar. When happy with how the avatar looks, they press done to go back to the closet scene. In the user info scene, it shows the amount of seconds the user has played as well as all their achievements. If the user hasn't unlocked a certain achievement yet, it will be set as "???". Finally, when the user presses the finish button, it takes them to a scene where they can view all three avatars at once and has a quit button to exit the game.

# Implementation manual: 
The menu makes use of the other classes that were created. For the avatar class, we have the Hashmap which stores the images for the shirts, pants, and hair. The methods for getting the previous and next clothings/items start at the current clothing index and goes forward or backward in the list. The skin tone and gender methods get the image paths for the images so when they are used for the Boy, Girl, and Neutral classes, we use the setter to set the path. Each Girl, Boy, and Neutral class contains the image paths that belong to each group. In the menu, there are three avatars created with the Avatar class. The menu uses imageview to display all the clothes, hair, and bodies in Javafx by getting it from the Hashmap and gender classes. The clothing are all stacked to the avatar currently chosen with stackpane and the done button saves all edits from the current avatar to the specific avatar that was being customized.  Naming the avatars uses labels, textfields, and buttons to change and show the name. Once named, the textfield is hidden until the user clicks the edit name button again. 
In the user class, we have a username that the user inputs as well as a timer which counts the seconds that the scene is run for. This is implemented in the menu when asking the user for their username and it gets used in the user info scene along with the timer. The Achievements class has getters and setters for the name and description of the achievements and a toString that returns them. The Achievement Manager contains an arraylist of achievements that are created in the menu. The Manager check to see if an achievement is unlocked and returns a boolean. There is also a method that returns all the achievements as a string. All of the achievements are displayed on the user info scene and when unlocked, it shows up in the scene.
